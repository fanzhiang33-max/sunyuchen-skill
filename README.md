# 孙宇晨 · AI 时代成长督促技能

> 把「AI 化、健康化、未来化」变成年轻人每天都能完成的一小步。
>
> 一个遵循 `SKILL.md` 规范的可安装技能：每天督促你完成一项 AI 行动、一项健康行动、一项面向未来的行动，并在晚间用三个问题完成复盘。

## 它解决什么问题

年轻人在 AI 时代最常遇到的三类困境：

1. **知道该用 AI，但每天都没用起来** —— 缺少具体任务和反馈回路。
2. **知道健康重要，但总是排到最后** —— 缺少低门槛、可坚持的日常动作。
3. **焦虑未来，却在原地内耗** —— 缺少“先探图、再小步试验”的决策方法。

本技能不提供成功保证，也不制造焦虑。它只做一件事：**把宏大的自我升级，拆成今天就能做完、并且能留下证据的小行动。**

---

## 三个支点

| 支点 | 含义 | 每日最低标准 |
| --- | --- | --- |
| **AI 化** | 让 AI 参与一个真实任务 | 用 AI 解决一个小问题，并核验结论 |
| **健康化** | 维护身体与精力 | 一项适合自己的活动、恢复或休息 |
| **未来化** | 增加未来的选择权 | 学一点、探一点图、或做出一个小产物 |

三者接入同一个循环：

```
选一个小目标 → 做出可观察行动 → 记录证据 → 复盘摩擦点 → 调整下一步
```

## 安装

技能以目录形式分发，安装即把 `sunyuchen` 目录放入你的技能目录：

```bash
git clone https://github.com/fanzhiang33-max/sunyuchen-skill.git
# 将 sunyuchen-skill 目录整体复制/链接到你的技能目录下，重命名为 sunyuchen
```

目录结构：

```
sunyuchen-skill/
├── SKILL.md                        # 技能主文件：触发条件、每日流程、安全边界
├── README.md
├── LICENSE
├── references/
│   ├── 访谈观点来源与转译.md         # 观点出处与“原话 / 转译 / 建议”的区分
│   └── api_reference.md            # 对话场景、输入默认值与验收标准
├── assets/
│   └── example_asset.txt           # 可复制的每日打卡卡片
└── scripts/
    └── example.py                  # 离线卡片生成器（零第三方依赖）
```

## 使用示例

**早上，要一份今日计划：**

> 用 20 分钟版督促我今天 AI 化、健康化、未来化。我现在在学英语，精力 3/5。

**晚上，回来复盘：**

> 我今天只完成了 AI 部分，走路没做。帮我找阻力，并把明天目标缩小。

**面临重要选择：**

> 我想在两个工作机会之间做决定，先帮我探图，区分已知事实、预测和需要验证的假设。

### 离线生成一张卡片

```bash
python scripts/example.py --minutes 20 --energy 3
python scripts/example.py --minutes 45 --energy 1 --date 2026-10-14
```

输出示例（20 分钟版）：

```
2026-10-14 · 练习反馈 · 20 分钟版
- AI 化（约 7 分钟）：请 AI 就当前学习主题出三道练习题，核对解析。完成证据：记一行结果。
- 健康化（约 6 分钟）：做一段适合自己的活动或恢复；不适时改为休息。完成证据：记一行结果。
- 未来化（约 7 分钟）：列出你感兴趣方向中的一个真实需求，并想一个访谈问题。完成证据：记一行结果。
今晚复盘：做了什么？哪里最难？明天继续、缩小、替换还是暂停？
```

脚本**不联网、不保存数据、不主动推送**，只做本地文本输出。

## 安全与边界

本技能在设计中刻意做了以下约束：

- **AI 是辅助，不是裁决者。** 医疗、法律、金融、就业去留等高影响事项，不以单一模型（或多个模型“投票”）代替专业判断与本人决定。
- **健康建议个体化且非医疗化。** 不诊断、不处方、不照搬访谈嘉宾的体重、热量、补剂或训练数据；有伤病或疾病时以医生和康复专业人员意见为准。
- **不索取敏感隐私。** 不要密码、验证码、密钥、证件或非必要的病历与财务明细。
- **不羞辱、不施压。** 未完成时先找阻力、缩小行动，而不是贴“懒惰”标签。
- **不会自动推送。** 技能包本身无法定时给所有人发提醒；如需每日定时督促，请自行配置个人提醒。
