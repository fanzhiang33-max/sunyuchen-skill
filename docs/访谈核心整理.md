## 二、摘要：这场对话在讲什么

这场访谈围绕一个具体问题展开：一个20岁、没人脉、没资源、月可支配收入不足1000元的年轻人，今天该如何开始？孙宇晨给出的答案是一套"零成本人生操作系统"：

- **掌舵者是 AI**。不是偶尔问一句的聊天工具，而是持续摄入个人数据、参与日常决策的底层系统；数据存本地 Markdown 文件，通过 API 调用全球各家大模型，不绑定任何一家平台。
- **三套理论打底**："孙学"负责认知与财富观升级，"薄肌"负责把身体当核心资产管理，"黄毛"负责屏蔽外界的嘲讽与打压，保证执行不打折。
- **方法论**：重大决策前先"探图"——用 AI 把选项和信息全面打开再下注；商业机会在全球范围内找，不盯家门口。
- **财富观**：先自由，后财富。自由是主观认知的解绑定和行动上的机动性，财富是认知到位后的伴生品。
- **后半场转向更大的问题**：TRON 与 Crypto 的本质是"把货币翻译成机器听得懂的语言"；婚姻感情他承认没有答案；人生意义他主张"体验大于结论"；他的长期计划是创业100年（22岁到122岁）。

一句话概括：**用 AI 武装认知，用薄肌维护碳基服务器，用黄毛屏蔽噪音，保持机动性，把世界当成一个持续版本更新的游戏来玩。**

## 四、分章详录

### 第一板块：AI 托管的一天（00:42–08:02）

这是全场对话的起点。孙宇晨刚练薄肌一天，用自己的一天展示了"全面 AI 化"具体长什么样。

- **身体数据**：身高172cm，体重约75公斤，体脂率约29%；计划用3到6个月完成整体形态重构。
- **饮食**：每餐前拍一张餐桌照片，吃饱再拍一张"残局"，全部丢给 Claude。Claude 计算卡路里和蛋白质摄入，并给出进食顺序建议（先吃高蛋白）。每天补蛋白粉25克、肌酸5克，蛋白质目标140–150克/天。
- **训练**：教练在旁边拍训练视频，上传给 Claude Code。AI 记录动作（硬拉、深蹲）、每组次数（12次×3组）、重量，按"渐进超负荷"（Progressive Overload）原则规划下一次递增。首日训练消耗275千卡，也被记录。
- **睡眠**：佩戴 Oura Ring，睡眠和卡路里数据直接对接 Claude Code；摄入减去消耗，热量缺口控制在600千卡内，增肌减脂同步进行。
- **日报**：Claude Code 每天汇总睡眠、饮食、训练，生成可视化健康日报。
- **数据架构**：所有记录存本地 Markdown 文档，照片存本地文件夹。"我们把 Claude Code 请出去，换 Codex，也可以直接来读 README.md，资料全都有，可以接着做。"
- **一个细节**：他花了一周做"理论建设"——准备 Oura Ring、逐帧逐句读邵艾伦的《薄肌圣经》并喂给 AI，还顺带纠正了自己对蛋白粉的偏见（"蛋白粉、肌酸不属于科技，就是普通的营养补充"）。

### 第二板块：零成本起步与方法论（08:02–47:01）

#### 1. 重回20岁的答案（08:02）

核心场景设定：月可支配收入不超过1000元（他在北大时就这个水平）。结论是**完全可以零成本 AI 化**：

- 注册智谱、Kimi Code、Z Code 这类免费工具，或他自己做的多模型聚合产品 B.AI；Claude Code 每月200美元太贵，但"今天智谱免费，明天 Kimi 免费，嫖各种额度，其实不用充钱"。
- 没有电脑就用手——"电脑都没有，一台手机总有吧，丢到手机里面也可以，建个文件夹。"
- 他把这一步类比为"日本先搞君主立宪、完成现代化"：**先 AI 化，这是第一步，无论多少钱都可以开始。**

#### 2. 三件套：孙学、薄肌、黄毛（08:02–16:28）

- **孙学**：用理论武装自己，"相当于升级大脑，换操作系统"——升级对金钱、对财富自由、对万事万物的理解。2016年提出，至今十年。
- **薄肌**：把身体健康作为核心资产。"身体健康如果不能保持，那是一票否决。"肥胖会严重拖慢财富自由的进度。
- **黄毛**：在华人社会践行小众理论"绝对会遭到很多反弹"，会被打压、嘲笑、嫉妒——"你又帅、又有肌肉、还有钱、还有认知，就会遭到嫉妒，这是百分之百的。"黄毛理论就是精神护甲：别人说什么不用管，自己认定对的事充分执行。
- 三者合计"只是认知升级，一分钱不花"。他测算中国20–40岁年轻男女约四亿人，都可以用这套理论升级自己。

#### 3. 怎么用 AI（16:28）

- **第一步攒数据**：把现状、健康、睡眠、饮食、学习进度全部记录成文档，先积累两到四个月，统一数字化后交给 AI 分析。
- **第二步多模型会诊**：同时问 Claude、OpenAI Astra、智谱 GLM 三个模型，"给你出上中下三策，取其中即可"；不想包月就走 API，问一个问题付一个问题的钱。
- **第三步执行与反馈**：照方案执行，把结果反馈给 AI 持续微调（tuning）。"大模型也是这样训练的……最后就像训练模型一样，把它训练出来。"
- **分工比例**："如果是开飞机，90%的时间让 AI 开，我自己可能就10%的时间调一下。"
- **经典语录升级**：他以前说"不要跟微信聊天，要跟豆包聊天"，现在升级为——"**用 API 跟全球的 AI 聊天。**"

#### 4. 探图：决策方法论（39:06）

这是被外界整理稿引用最多的方法论，用游戏"探图"作类比：

- **买房先看100套**。数学依据是经典的"37%参照系模型"：前三套绝对不买，用来建立基准（Benchmark）；第四到第六套一旦出现比前三套都好的，立刻决定——"到第六套，有0.618黄金分割线和概率上的考虑，第六套如果最好，是最好的情形。"
- **择业先看100个专业**。"现在有 AI 了，你可以一夜变身张雪峰"，让 AI 逐个分析就业情况并推导未来十年；同样的高考分数，不一定挤清华北大，海关学院这类"名字不响亮但出路好"的小众专业也在选项里。
- **核心逻辑**：过去决策失败"要么是第一套就盲目下定，要么是看了100套因选择瘫痪而错过最优解"。"先造几个斥候把地图打开……更何况现在探图是免费的。"

#### 5. 全球商机（33:02）

- **例子：API 地区价差**。同样的 AI 服务，在阿根廷、土耳其、尼日利亚包月便宜，在美国包月最贵——做 Token 中转站，让贵的地方用上便宜的服务，价值就成立了。
- **度量衡要变**："千万不要想着在家门口开个小卖部，挣楼下老奶奶的钱，这个尺度太小了。"把尼日利亚人、土耳其人、阿根廷人都想象成客户；语言不是障碍，AI 可以解决。
- **终局判断**："四亿年轻人被 AI、被孙学黄毛薄肌武装之后，去为全世界的80亿人服务，未来可能还有20亿 AI。四亿人去服务100亿的人和 AI，就不用内卷了。"
- **智商论**："世界上不存在智商这个东西，只存在信息多少的区别。所谓智商差距，本质是信息量和训练量的差距。"

### 第三板块：看好的赛道（47:01）

他给年轻人指了五个方向，共同标准是"有大量现成数据、AI 能处理"：

| 方向           | 他的理由                                                                      |
| ------------ | ------------------------------------------------------------------------- |
| 数学           | 最吃"家学"和圈层的学科，AI 把全世界的思路抓进模型，"乱拳打死老师傅"                                     |
| 天文学          | 哈勃望远镜已读回大量数据，无人处理，AI 补位                                                   |
| 生物/制药        | 数据大量积压，"一个药实验通过，就是大炮一响，黄金万两"                                              |
| 基因测序与健康管理    | 个人全基因数据+AI 分析，预测未来健康                                                      |
| Crypto 与数据服务 | 全球支付系统+天然适配 AI 的 API 级微支付；数据清洗/标注（"别瞧不起数据标注，Scale AI 一百多亿美元卖给了 Facebook"） |

两个标志性案例：

- **孙宇晨奖**：鼓励把数学证明翻译成 Lean 形式化证明，让机器能读懂，"也是为了铺垫 AI 时代"。
- **NYU 教授与 OpenAI 的 NS 方程之争**：纽大教授把攻克纳维-斯托克斯方程（千禧年难题）的思路讲给 OpenAI，OpenAI 调集700万美元算力和数千个 Agent，两天沿该思路攻破。他的评论："教授的思路很关键，他不提供，模型也不知道；但他一提供，两天就做出来了。"由此判断："一个15岁的年轻人，可能很快就超过50岁的老教授。"

他还有一句被广泛转发的判断："未来只要稍微努力一点，'人均诺贝尔奖'真的不夸张……一个大学生加上 AI，速度可能很快就超过一个诺贝尔奖得主。"同时他坦承："我今年36岁，还剩四年这样的黄金时间，我都有点觉得自己落后了。"

### 第四板块：健康、薄肌与主动管理（52:46–01:22:07）

这是全场篇幅最大、也被剪成切片传播最广的板块。

#### 1. 寿命的100分模型

他请教 AI 后得到的框架：寿命总分100分——

- 心肺功能 25分
- 肌肉含量 25分
- 器官维护、基因、眼睛牙齿等 50分

结论：抗阻训练（深蹲、硬拉等复合动作）一次拿满前50分；只跑步会掉肌肉，等于放弃另外25分。肌肉像《王者荣耀》的红莲斗篷——"自带范围伤害，贴着对方就扣血"，睡觉都在被动燃脂。

#### 2. 肌肉是资产

- "**肌肉就是你身上的美金存量，要存起来。**"身体应激时先扣肌肉——生一场大病先消耗肌肉，日常不补充就是在透支。
- "薄肌会取代美金不是开玩笑，比美金还关键。美金没了可以再赚，有薄肌，扛大包也能赚钱。"
- **司美格鲁肽警告**：这类减重药在减脂同时造成肌肉大幅脱落，基础代谢率断崖下跌，形成"越打药→代谢越低→停药反弹→肌肉更少→晚年肌无力、极易骨折卧床"的恶性循环。
- **巴菲特之问**：AI 只用一句话说服他——"你跟巴菲特吃过午餐，他是自己走进餐厅的，还是别人推着轮椅推进来的？80岁的时候，你想自己走进来，还是被推进来？"

#### 3. 认知转弯：从排斥健身到薄肌信徒

他完整交代了自己的观念转变史：年轻时认为"练肌肉是为了泡妞""练肌肉的都打了科技""有肌肉不健康"，一度刻意多练有氧、避开器械。这次转变用了约两周，他把过程类比为"从闭关锁国走向改革开放"。触发点除了风波中的网暴，更重要的是 AI 的一句话：

> "你现在物质上可能是个富人，但身体上是个穷人。"

他还点评了三位"宾大校友"（马斯克、巴菲特、特朗普）不健身的现象，判断是"屁股决定脑袋"——"没做出改变之前，因为他不是薄肌，就会替大肚子说话。"并点名马斯克在 Bryan Johnson 健身对比帖下留言 "You look better before"（你以前看起来更好）是传播错误认知，"吃亏最大的是他自己"。

#### 4. 主动健康管理

- 他没生病也"天天去医院"，因为 AI 告诉他要测哪些项目：高血糖、高血脂、高密度与低密度脂蛋白，先摸清底数再指导训练。医生问"你是不是最近用了 AI"，并说在他看过的病人里，"我是第一个没有任何身体症状、纯粹由 AI 驱动来进行主动健康排雷和数据监控的人"。
- 他的原则："健康需要自己管。每次冲进急救室喊'不惜一切代价抢救'，已经晚了。"
- 时机判断：肌肉含量最大值在40岁后下降，"20岁到40岁，薄肌是必练，这时候投资回报比最高"；王石70岁开始练，"可能是勉强保证不用坐轮椅"。

### 第五板块：战略观——逐水草而居（01:22:07–01:32:26）

#### 1. 下一个十年怎么规划

他借游牧民族的五个字回答：**逐水草而居**——哪里有水草就到哪里住。顺带纠正了一个历史偏见：辽、金在课本里被妖魔化，"是因为我们屁股坐在宋那边；今天都是一家人，凭什么低一等"。

落到操作层：

- 哪个地方、哪个行业能发挥最大价值，就去哪里；"能不能赚到足够的钱，也是一个标准——赚得多，说明你在这里创造的价值大。钱可以看作数据。"
- 行业溢价是真实的：西贝做十几年快倒闭，DeepSeek 做几年冲向万亿美元估值，"同样一个人，做 AI 就是比做焖面价值大"。

#### 2. 为什么劝30岁前不买房不买车不结婚

他的原话括号备注是"指不过早锁定流动性"。例子很具体：

- "明天 OpenAI 录取你去旧金山，你跟他说我在北京买了房能不能在北京工作——大概率不同意，你就失去这个机会了。"
- 他见过优秀人才因为要跟妻子商量而拒绝 Offer："妻子那份月薪5000元的稳定工作不愿意辞职，我们能给他月薪四万，最后他只能留在原地拿两万。"

#### 3. 600万美元的香蕉

针对"为什么花600万美元买香蕉不买黄金钻石"的质疑，他的解释：

- "香蕉是概念艺术，在网络上传播，本质上是流动的 IP。只要我同意，全世界任何一家博物馆，明天都可以贴香蕉来展览。"
- "黄金、珠宝是实物，放在一个地方，带不走，还容易被偷。这个香蕉怎么偷？它永远跟我的名字绑在一起。"
- 由香蕉推广到薄肌理论："小众说明是风口。大家都接受了，就没有那么多价值了。现在不接受、争议多，我来传播这个理论，才体现出价值。"

### 第六板块：TRON 与 Crypto——让机器读懂货币（01:32:26–01:50:14）

#### 1. 一句话定义

"我们做的事情很简单：**把货币翻译成机器、互联网能听得懂的东西。**"

论证链条：

- 招商银行、PayPal 只是"传统货币的数字化"，账本仍是中心化服务器管理；TRON、比特币是"完全按照密码学、数学的方式运作，机器一下就能明白你在干什么"。
- SWIFT 是20世纪50年代二战盟军电报系统的遗产，"那个时代没有计算机、没有 AI，你不能指望它跟这些东西兼容"。
- 与孙宇晨奖同构："数学证明要变成 Lean 形式化证明让机器读懂，货币也要变成机器听得懂的语言。"

#### 2. 语料论（本场最激进的观点之一）

- "**如果一个东西未来没有成为 AI 的语料，这个东西就像从来没有发生过。**"
- 例证：500年前一个有5000万人的国家没有留下文字记录，"最后全都灭亡了，后来的人不知道他们存在过，AI 也读不到"。
- 费马大定理："他有可能知道思路，但没有分享出来，人类又花了一百多年才找到下一个能证明的人。如果在 AI 时代，他哪怕用语音把思路讲两句，可能早一百多年就证明了。"
- 由此谈到自媒体："我们应该允许所有人发言，每个人表达观点、相互辩论，才更有可能接近真理。"抖音、YouTube、推特的兴起，本质是表达权的去中心化。

#### 3. 规模与杀手级应用

- TRON 现状（他的口径）：每天处理交易量几百亿美元，一年发送总量几万亿美元。邵艾伦的比喻："修了一条高速公路，来来往往的车都在这条链上行驶，TRON 收通行费。"
- 杀手级应用：跨境转账、稳定币支付、人向 AI 付费、AI Agent 之间的支付——"一个 Agent 调用另一个 Agent 的 API，按毫秒级算力结算，金额可能只有几分之一美分。传统银行既无法支持这种精度，也无法承担手续费和结算延迟。"
- "100年后还会有多少人用纸币？"

### 第七板块：投资逻辑与争议（01:50:14–02:02:14）

#### 1. 系统更新式的投资观

- 他2012年以后"全部 Crypto 化"，早期买比特币"不是为了赚钱，跟现在练薄肌一样，只是为了系统升级"。
- 2007年第一次见 iPhone 就买了很多苹果股票，"但也没有参与做手机"；2012年见特斯拉，"第一次看到就觉得它是革命"。
- "系统只能往前更新，不能一直扛着不更新。否则后面越来越多的东西不支持你的版本。"
- **赚钱是副产品**："为什么赚钱多？因为社会对它的评价高。为什么评价高？因为它在社会里扮演的角色越来越重要。"

#### 2. 动机论批判

风波后有人扒他的"黑历史"（看牙医不给钱、买东西不给钱等），他的回应：

- "他们编这些东西，想证明我是坏人，所以我做的事情、赚的钱也是坏的。这没有逻辑。"
- 例子：健身博主提倡健身，有人曝光他出轨50个女人——"就算他人品不好，能证明练肌肉这件事是坏的吗？"
- 同类现象：马斯克前女友说他做 AI 是为了奴役全人类；Sam Altman 的家人说不要相信他。"评价一个人做的东西有没有用，应该跟对他本人的评价分开看。"

#### 3. 投资与主业不必同赛道

针对邵艾伦"能力在内容、投资重仓 Crypto，要不要合并"的提问，他明确说"倒也不一定"："做内容与投资可以并存。2007年我买苹果股票，但也没有参与做手机。你看好一个产业，不意味着必须亲自去上班。"

### 第八板块：认知论——Small Ego 与版本更新（02:02:14–02:40:44）

#### 1. 自媒体与个人影响力

- "首先自媒体就不错，这是一个做多自媒体的时代。"Joe Rogan 的影响力已达 CBS 整个电视台的级别，"但他一开始是为了控制选票才做播客的吗？不是，就是想做自媒体。"
- 个人 IP 的价值不只流量："把自己解决过什么问题、方法论、可验证的成果留在网上"，让搜索引擎和 AI 也知道你。

#### 2. Small Ego（小我）

- 出处：张一鸣说字节能持续赢，重要原因是 Small Ego——"无论多成功，仍然愿意听年轻人说什么，愿意学新的东西。"
- 诅咒："越有钱、越成功，Ego 越应该小，才能保证在下个版本继续成功。但往往像个诅咒：越成功，Ego 越大。"
- 巴菲特例："我苦劝他投资特斯拉、比特币，他不符合自己的投资逻辑就不投。他账上有3000亿美元，拿出300亿都可以买很多。"
- 他的自我应用：网暴中流传他与张继科的身材对比图，"我就像 AI 一样，立刻把这张照片里的信息吸收为自己所用——第一要练，第二先练深蹲，因为腿部肌肉最多。Small Ego：把别人的理论和经验，迅速转化成自己的行动。"

#### 3. 学习之后有没有行动，才是关键

- 他引用 Alex Hormozi 的智商公式：新信息是分母，行为上的改变是分子——"根据新信息做出的改变越大，就越聪明。"
- 再证智商论：GPT 从被笑"人工智障"到破解 NS 方程，"主要区别是输入的信息……放到人身上，认知会改变行为模式，行为模式又会改变结果。"
- 六边形战士警告：韦东奕数学极强，但"年纪轻轻牙齿都掉光了……牙齿没了是不可逆的，装假牙功能也比原来的差。不能只觉得自己研究数学就行。"

#### 4. 版本更新：把世界看成游戏

- "一代版本一代神。"《王者荣耀》大版本更新会改英雄强度——"你李白练得很好，下个版本大砍李白。"
- 类比现实："上帝更新一个大版本，就可能削弱你的英雄。比如更新说明写：房地产削弱50%，AI 加强100%。"
- 案例：王健林看到 AI 大版本该赶紧更新，"自己不懂也可以投资 DeepSeek、Kimi、智谱。碧桂园投长鑫存储赚了几倍，很快就卖掉了——没握住，认知还没到。"
- 邓小平例：从计划经济到市场经济，"在那种权力地位下，能转这么大的弯，很不容易。能做到180度转弯，再加上那么强的能力，就是伟人级别。"
- 对年轻人的推论："上一代成功的人转不过来，才给下一代留下空间……你说自己起点低、没钱，这是好事，因为没包袱。"

### 第九板块：财富自由再定义（02:40:44–03:03:03）

#### 1. 十年后的答案：先自由，后财富

- "2016年的版本，现在又打上薄肌的补丁。"
- 核心六字："**先自由，后财富。财富是自由的伴生品。**"
- 逻辑："很多人以为有钱了才能自由，其实恰恰相反——思维先解除束缚（不被固定资产锁死、不被舆论绑架、敢于跨界套利），才能敏锐捕捉时代风口。"
- 好消息："自由有很大一部分是主观的，尤其年轻人，你决定给自己自由，就已经可以开始。"
- 飞轮：更自由→更容易获得财富→财富加强自由，螺旋上升；健康同理（练薄肌→睡更好→更有时间训练）。反过来是负循环：买房→花钱花时间维护→机会变少→钱更少。

#### 2. 钱买不到的东西

- "真正有钱之后，什么东西解决不了？还是认知。认知只能靠自己感兴趣、下功夫、认真学，光给钱没用。"
- 中彩票类比："上帝一打响指让你突然拥有一身薄肌，但你没学过主动健康管理，每天炸鸡麦当劳，六个月后可能又胖回去。"突然获得财富也一样，"没学会怎么管理、再生产，钱可能流向坏习惯，反而变成诅咒"。
- 他提到一类互动短剧游戏（设定"突然中500万、3000万"）："如果中了3000万最后玩到破产，就说明认知还没达到能掌控3000万的程度。"

### 第十板块：人生哲学（03:03:03–04:16:34）

#### 1. 婚姻与感情：承认没有答案

全场少有的"没有结论"的章节，他的表态很坦诚：

- "我也在摸索。如果有固定答案，就不会有上个月那场风波。"（指此前的"世纪之问"——那5000万如果给了，她还会不会走；他对网上"给50亿、500亿也会走"的推导表示同意。）
- 两点思考：一，"感情跟有多少钱确实不是一回事。钱像一个放大器——前面有'爱还是不爱'这个更根本的输入：爱，可能更爱；不爱，还是不爱。"二，"感情特别主观……清官难断家务事，再聪明的人也很难断别人的家务事。"
- 边界："我没结过婚，只在婚姻边缘摸索了一下，不敢贸然说自己比有婚姻、有家庭的人更懂。"他也指出这是时代性问题："中国有两亿没结婚的人，美国、韩国、日本都有类似情况。"
- 邵艾伦提出私下交流自己"黄毛思维"视频里的感情逻辑，孙宇晨回应："好，你先把视频发给我，我认真看一下。"


#### 2. 人生意义：玩家心态

- "我是玩家心态，相当于被人扔进了'地球 Online'这个游戏，现在还处于探索期。"
- 类比 AI 黑盒："为什么大家恐惧 AI？因为连最强的研发人员也没搞清楚大模型里面的推导机制怎么形成，一切靠猜和做实验。人生也是这个混沌体系。"
- 由此定下规则："按人类寿命上限算，前50%先看、先灌数据，不急着下结论；后50%如果有了把握，再说。"
- 儿时答案被自己推翻："以前想为地球做贡献——去了一趟太空发现不对，人类过些年可能都离开地球了；想为人类做贡献——AI 都出来了，未来有没有别的智能生命体也不一定。知道得越多，越不敢下结论。"

#### 3. 为什么上太空

- 对"炒作论"的正面回应："我上太空，第一不是为了炒作，第二不是为了荣誉，就是带着实验的态度，单纯想体验。没上过太空之前，你对太空做出的任何评论都很无力。先上再说，获得更多信息。"
- 对"上得不够远"质疑的回应："我自己还不确定上太空是不是适合我，先试一下。回来有了体验，再决定要不要去月球、去火星。眼前这次体验的投入产出比合适，就先云。"
- 结论句："**体验可能大于结论。**人生的意义，可能就是你的体验的集合。"他推荐《瑞克和莫蒂》："无论莫蒂得出什么结论，瑞克马上就能带他去宇宙另一个地方找出反例。"
- 对处境艰难的人的一句插话："先别急着给人生下最后的结论，别急着结束，再等等、再看看。没有什么一定要立刻下结论。"

#### 4. 为什么继续创业：创业100年

- 博尔特类比："他在乎的体验可能是，跑到9秒80之后，能不能9秒70、9秒50？不断突破，代表的范围也在变——从牙买加最快，到人类最快。"
- "商人、企业家比较幸运，这个职业的寿命很长。运动员的职业周期可能只有十年。"
- 具体计划："我22岁开始创业，当时了解到的人类寿命极限大约是123岁，觉得22岁开始做到122岁，正好创业100年，可以挑战创业时间最长的纪录。"
- 进度："从2012年到2026年，已经14年，100年的进度条走完了14%。跟巴菲特比不算什么，跟自己比，已经走了一段路。"

#### 5. 三个商业标杆

他不搞门派之见，以三位宾宾校友为坐标系，各取所长：

| 标杆 | 学习的象限 |
|---|---|
| 埃隆·马斯克 | 工程与科技，工程师时代的高精尖 |
| 沃伦·巴菲特 | 金融与长青，长期主义、超长待机、滚雪球 |
| 唐纳德·特朗普 | 个人 IP 与跨界，影响力运营的极致 |

- "三位大神互相看不上，但不妨碍我们吸收每个人的长处。不要过早把自己定型，成大学问者都是兼收并蓄。"
- 终极追求："成为别人的 benchmark，成为后来者的人生坐标系。挣钱只是积分，本质是不断突破人类商业体验的极限。"

#### 6. 财富自由之后想去上班

- "我开玩笑说想去 AI 公司上班——OpenAI 或者 Anthropic，愿意为 offer 付5000万美金。因为自己缺少从普通员工向上观察公司的经历。"
- 人生规划观："每个人可以有大致方向，但最终结果也会受到经历和偶然事件影响。回头能讲出一条清楚的故事，不等于出发时就知道所有步骤。"

#### 7. 收尾：多创造，少消费

- "现代人大部分的问题是创造不够、消费太多。"
- 行动准则："**多创造，少消费，然后你做什么基本上都是对的。**"创造可以是一项服务、一件产品、一篇文章、一个工具，"消费让你获得体验，创造让体验留下结果"；休息和消费可以为下一轮创造补充精力，不必追求100%创造。
- 关于 AI 润色："工具可以帮助整理表达，但创作者仍需要有自己的经历和输入。没有经历，单靠润色写不出属于自己的内容。"

## 五、出圈观点清单（传播最广的十条）

1. **零成本 AI 化**：月可支配收入不到1000元，用免费 AI + 手机 + 本地 Markdown 文档，就能把生活全面 AI 化。
2. **孙学、薄肌、黄毛"新三件套"**：认知、身体、心态——和先天决定的"高富帅"不同，全部可以后天打磨。
3. **用 API 跟全球的 AI 聊天**（由"不要跟微信聊天，要跟豆包聊天"升级而来）。
4. **先探图，再出兵**：重大决策前用 AI 看100个选项建立参照系；前三套建基准，第四到第六套出现更优立刻定。
5. **30岁前不买房、不买车、不过早结婚**：保持"逐水草而居"的流动性。
6. **肌肉是你身上的美金存量**：寿命100分=心肺25+肌肉25+其他50；抗阻训练一次拿满前50分。
7. **司美格鲁肽陷阱**：减脂掉肌肉→代谢断崖→反弹→晚年肌无力的恶性循环。
8. **没有成为 AI 语料的东西，相当于从未发生过**：知识、证明、经历都要数字化上传。
9. **Crypto 是把人类古老的货币翻译成 AI 和机器听得懂的可编程语言**：SWIFT 是电报时代的遗产。
10. **先自由，后财富；多创造，少消费**：财富是自由的伴生品，人生意义是体验的集合。
